# Contributing to Open VIP Portfolio

Thank you for your interest in contributing! This project welcomes improvements, bug fixes, and new protocol VIPs.

## How to Contribute

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/my-improvement`)
3. **Commit** your changes with clear messages
4. **Push** to your fork
5. **Open** a Pull Request

## Guidelines

- All source code must include the Apache-2.0 license header
- Follow SystemVerilog/UVM coding standards
- Include protocol checker for each VIP
- Update `vip_individual_portfolio.csv` when adding new VIPs
- Ensure each VIP is self-contained and can run independently

## Code of Conduct

Be respectful and constructive in all interactions.

## Questions?

Open an issue on GitHub for discussion.
